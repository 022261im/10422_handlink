# TRACE — 암기 과목 시험 대비 웹사이트

교과서·수업 프린트 파일을 등록하고, AI가 만든 학습 콘텐츠 초안을 검토한 뒤 퀴즈·빈칸 복원·개념 비교로 학습하는 프런트엔드 프로토타입입니다.

## 포함된 화면
- **대시보드:** 자료 수, 확정 문항, 복습 대상, 정답률과 학습 사이클
- **시험 범위 & 자료:** 파일 등록, 직접 텍스트 입력, 원문 확인 및 자료 관리
- **AI 자료 제작실:** 콘텐츠 유형 선택, 초안 생성, 질문·정답·해설·원문 근거 수정, 문항 확정 또는 제외
- **통합 학습실:** 다양한 퀴즈, 빈칸 복원, 개념 비교, 확신도 기록, 원문 근거 확인
- **학습 분석:** 정답률, 풀이 기록, 확신도, 문항별 상태
- **복습 계획:** 오답 및 미학습 문항을 중심으로 복습 큐 제공

## 실행
index.html을 브라우저에서 열거나 GitHub Pages를 활성화해 정적 웹사이트로 배포할 수 있습니다.

## 현재 프로토타입의 범위
- TXT, MD, CSV는 브라우저에서 텍스트를 직접 읽습니다.
- PDF, DOCX, 이미지의 텍스트 추출은 외부 브라우저 라이브러리 로드가 가능할 때 시도합니다.
- 자료, 문항, 풀이 기록은 현재 브라우저의 localStorage에 저장됩니다.
- **실제 LLM API는 아직 연결되어 있지 않습니다.** 제작실의 초안 생성은 원문 기반 데모 로직이며, 실서비스에서는 서버 측 AI API, 사용자 인증, 데이터베이스, 파일 처리 및 개인정보 보호를 추가해야 합니다.
- API 키를 프런트엔드 코드에 직접 넣지 마세요.

3. 사용자 계정과 데이터베이스를 통한 기기 간 동기화
4. 실제 시험 일정 기반 간격 복습 및 자동화 테스트
